# Cats vs Dogs Classification using SVM

## Description
This project classifies images as either Cat or Dog using Support Vector Machine (SVM).

## Technologies Used
- Python
- OpenCV
- Scikit-learn
- NumPy
- Jupyter Notebook

## Dataset
Microsoft Cats vs Dogs Dataset

## Algorithm
- Support Vector Machine (SVM)

## Steps
1. Load images
2. Resize images
3. Extract labels
4. Train SVM classifier
5. Predict image class

## Output
- Cat prediction
- Dog prediction
- Model accuracy

## Result
The model successfully classifies cat and dog images.
